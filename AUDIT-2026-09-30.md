## Needs review (not changed)

- **Clear IK Pose (Alt+Shift+R) cannot clear keyframes on 5.x** (`daz_bone_select.py` ~13090). It uses `action.fcurves`, which was removed in 5.0. The `hasattr` guard turns this into a silent no-op. Port it to the channelbag API, which is already used at ~7209.
- **Operators that change data but lack `bl_options={'REGISTER','UNDO'}`:**
  - the pin/unpin operators (`DAZ_OT_pin_*`, `unpin_*`, `toggle_pins`)
  - PoseBlend `add/delete/duplicate/rename/update_dot`, `add/clear/delete/rename_grid` and `import_grid`
  - PoseBridge `register_character`, which creates objects

  Some of these run while the main modal is active, so test undo pushes live before adding UNDO blindly.
- **Stub operator still registered.** `posebridge/interaction.py` registers `view3d.posebridge_interact` as an all-TODO stub. Its `invoke` returns RUNNING_MODAL without `modal_handler_add`, and nothing calls it. Unregister or remove it.
- **Dev path in shipped code.** `dsf_face_groups.py:225` probes `D:/Daz 3D/import-daz-paths.json`, and there is no fallback to the default `My DAZ 3D Library`.
- **Maintainer email.** `blender_manifest.toml` uses `josh@azra.ai`, a former employer. The `website` repo URL is unverified.
- **Dead code, about 45 zero-reference functions.** Examples: `poseblend/viewport_setup.py` (5), `grid.py` (5), `posebridge/core.py` (5), `presets.py`, `icons.py`, and in `daz_bone_select.py` `apply_fabrik_to_limb`, `solve_two_bone_ik_analytical` (module-level duplicate) and `test_step1_create_ik_chain`.
- **Orphan modules (~1.8k lines), now excluded from the zip:** `daz_rig_manager.py`, `rotation_cache.py`, `posebridge/outline_generator_{body,curves,simple}.py`, `icons.py`, `extract_icon_shape.py`.
- **Nested `bl_info` in `daz_bone_select.py`, `poseblend/` and `posebridge/`.** Blender ignores these, and the names are stale ("DAZ Bone Select & Pin & PowerPose").
- **Console noise.** 55 `print()` calls remain in `daz_bone_select.py`, including per-frame `[FABRIK]` output. Move them to `log`.
- **`backup_extension_20260707/`** is 27 MB and untracked (gitignored). It is not in git, but it is dead weight on disk next to four stale `.backup_*`/`.recovered` files and two old zips. Safe to delete once confirmed.
