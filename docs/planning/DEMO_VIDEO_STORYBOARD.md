# BlenDAZ Demo Video — Storyboard

**Target**: 60–90s, 1080p60, 16:9, real-time capture (no speed-ups on the hero shots — real-time IS the pitch). Style reference: BGEN Picker announcement (2026-08-06) — fast cuts, minimal text overlays, one feature per shot, no talking head.

**Tagline candidates**
- "Pose DAZ characters the way DAZ artists expect — in Blender."
- "No bones. No pickers. Just click the character."

## Shot list

Each shot: 6–12s, text overlay bottom-left, cut on action (motion mid-frame at the cut, never a static pose).

### 1. Cold open — direct mesh posing (the hook, 0:00–0:10)
Clean viewport (no overlays, no bones visible), G8 character, nice matcap/Eevee lighting.
Cursor hovers forearm → region highlights → click-drag → arm rotates with limits respected.
**Overlay**: "Click the character. Not the rig."
*This is the shot that must land in the first 3 seconds — X autoplays muted.*

### 2. Pin maintenance (the differentiator, 0:10–0:25)
Select hand → P to pin (icon appears) → pin the other hand → select hip → G-drag.
Hands stay planted while the body moves; limbs re-solve live.
**Overlay**: "Pin hands. Move the body. They stay put."
Then R-rotate the hip — pins still hold.
**Overlay 2**: "Rotation too."

### 3. Reach leash (0:25–0:33)
With a hand pinned, drag the hip away past full arm extension → hip leashes back instead of the pin breaking.
**Overlay**: "Over-reach? The body follows — like DAZ ActivePose."

### 4. PoseBlend blend pad (0:33–0:50)
Grid overlay in viewport, 4–5 named dots visible (labels are new — show them).
Drag cursor between dots → character blends in real time.
Then: Shift-click "L.Arm" on the Live Mask body map → drag again → only the left arm follows.
**Overlay**: "Blend saved poses on a pad." → "Mask any body part, live."

### 5. PoseBridge panels (0:50–1:05)
2D character outline with control points; click-drag a control point → body part moves.
Switch to hands/face view; pose fingers via panel.
**Overlay**: "Or pose from a visual map — body, hands, face."

### 6. Morphs/expressions beat (optional, 1:05–1:15)
PoseBlend expression grid blending FACS morphs between dots (smile ↔ frown drag).
**Overlay**: "Expressions blend too."

### 7. Closer (last 5s)
Character strikes final pose (use shot-2 footage end state), logo + name.
**Overlay**: "BlenDAZ — for DAZ Genesis 8/9 · Blender 5.0+" + link.

## Capture checklist

- [ ] Fresh scene, one attractive G8/G9 character (neutral outfit, good silhouette — the ogre reads poorly at small sizes; use a clean humanoid)
- [ ] Hide all N-panels except when the shot needs one; full-screen viewport (Ctrl+Space)
- [ ] Screen capture: OBS at 1080p60, mouse cursor visible + click highlight ON (viewers must see clicks)
- [ ] Blender theme default; viewport denoise/AO on for beauty
- [ ] Practice each shot until it's one clean take — no hunting the cursor mid-shot
- [ ] Record 2–3× more footage than needed; cut hard
- [ ] Export per-shot GIFs (shots 1, 2, 4) for the X thread + store page

## Post

- Cuts on action, no dead frames between shots
